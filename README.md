# Research Kit

**Experimental:** a third-party Flow Kit prototype for source-traced capture, compilation, and recall. This repository contains declarative flows and agent guidance, with no store or execution engine.

Start with the [documentation](docs/README.md) for the contracts, a scratch-workspace experiment, validation, and maintenance. Read the [authoring findings](FINDINGS.md) before installation; they record an earlier `@kontourai/flow-agents@0.4.0` experiment, not current release qualification.

The kit is a Git repository, not a published npm package. Its private development tooling pins Flow 5.2.0 for current container/definition validation and isolated local installation checks. Production use, provider behavior, and live activation are unverified here.
